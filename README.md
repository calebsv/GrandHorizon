# 🏨 Grand Horizon

> **Sua próxima experiência de luxo começa aqui.**

O **Grand Horizon** é um projeto de website para um hotel fictício, desenvolvido com foco em proporcionar uma experiência moderna, sofisticada e interativa para usuários que desejam conhecer acomodações, benefícios e realizar uma simulação de hospedagem.

🔗 **Demo:** [Grand Horizon](https://empgrandhorizon.netlify.app/)

---

## ✨ Sobre o projeto

O Grand Horizon foi desenvolvido para representar a experiência digital de um hotel de alto padrão.

A aplicação apresenta uma interface moderna e responsiva, permitindo que o usuário:

* 🏨 Conheça as suítes disponíveis
* ⭐ Visualize os destaques das acomodações
* 💎 Consulte os benefícios oferecidos
* 🧮 Simule uma estadia
* 🛎️ Adicione serviços e experiências extras
* 💰 Visualize o valor total da hospedagem
* 📅 Informe datas de check-in e check-out
* 👥 Informe a quantidade de hóspedes
* 📩 Envie uma solicitação de reserva
* 💬 Confira avaliações de hóspedes

A seção de simulação permite selecionar uma suíte, adicionar experiências e acompanhar o valor total da estadia em tempo real.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma experiência de reserva de hotel que vá além de uma simples apresentação visual.

A proposta é unir:

**Design + Interatividade + Simulação + Experiência do usuário**

Dessa forma, o usuário consegue explorar o hotel e visualizar uma possível estadia antes de finalizar sua solicitação.

---

## 🚀 Funcionalidades

### 🏠 Página inicial

Apresentação do Grand Horizon com uma chamada principal destacando a experiência de luxo oferecida pelo hotel.

### 🛏️ Suítes

Exibição de diferentes opções de hospedagem, incluindo:

* Deluxe Suite
* Suíte com vista para o mar
* Suíte com SPA incluso

Cada acomodação possui uma opção para iniciar o processo de reserva.

### 💎 Benefícios

A página apresenta benefícios como:

* Conexão
* Custo-benefício
* Reserva rápida

### 🧮 Simulação de estadia

Uma das principais funcionalidades do projeto.

O usuário pode:

1. Escolher uma suíte
2. Adicionar serviços extras
3. Visualizar os serviços selecionados
4. Acompanhar o valor total
5. Finalizar a reserva

O sistema apresenta inicialmente o estado sem suíte selecionada e atualiza o resumo conforme as escolhas do usuário.

### 📅 Solicitação de reserva

O projeto possui um formulário para solicitação de hospedagem contendo:

* Nome completo
* E-mail
* Check-in
* Check-out
* Quantidade de hóspedes

Após o envio, uma mensagem de confirmação é apresentada ao usuário.

### 💬 Depoimentos

Seção dedicada às avaliações de hóspedes, reforçando a proposta de confiança e qualidade do hotel.

### 📱 Design responsivo

A interface foi pensada para proporcionar uma experiência consistente em diferentes tamanhos de tela.
